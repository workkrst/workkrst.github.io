📥 1단 — 수집 자동화 (Day 2~3)

⛔ 비용 강제 규칙: 유튜브 수집 Apify 금지 — yt-dlp + YouTube Data API v3(무료 10,000 유닛/일)만 허용. 인스타만 Apify(빈도는 사용자 지정) · 모든 수집 빈도·횟수는 사용자 지정 사항

1-1. 벤치마킹 스캔 크론 (빈도: 사용자 지정)

  • 입력: 벤치마킹 계정 20개 (사용자 제공 예정)
  • Apify instagram-scraper로 계정별 최근 30개 포스트 수집 → 좋아요 대비 댓글 비율 상위 = 터진 퍼널 포스트
  • 출력: "어떤 셀럽×제품 조합이 도는지" 시트+텔레그램 리포트 → 훅 템플릿 라이브러리 축적

1-2. 셀럽 발언 소재 크론 (daily, isolated)

  • 유튜브 검색: 셀럽 후보명 × 식품키워드(다이어트/식단/먹는) → Apify youtube-scraper, 최근 클립 위주
  • yt-dlp 다운로드(후보만, clips/{날짜}_{셀럽}/) → faster-whisper STT → LLM이 "제품 연결 가능한 발언" 발췌 (예: "맨날 그것만 먹어요")
  • 제품TB 키워드와 자동 매칭 → 소재TB 기록
  • 후보 3개 텔레그램 승인 요청(셀럽/발언/클립 구간/매칭키워드) → 번호 선택 → 제작 트리거

🎨 2단 — 작성 자동화 (Day 4~6)

2-1. 슬라이드 1 (훅 카드)

  • 셀럽 프레임 캡처(유튜브) + 훅 문구 오버레이 — Pillow 템플릿 렌더러, 1080×1440
  • 훅 문구는 LLM이 포맷 기반 생성: "역대급 ○○된 ○○" / "○○가 매일 먹는 ○○" 등 (벤치마킹으로 지속 보강)

2-2. 슬라이드 2 (영상)

  • yt-dlp 구간 다운로드(--download-sections) → ffmpeg 9:16 크롭
  • 모자이크 처리: 제품명·제품컷 노출 구간 boxblur/delogo — 초기엔 시간대 수동 지정, 추후 자동화
  • 자막: whisper 원문 → LLM 후기체 재작성 → ASS 오버레이 → 1080×1920, 15~25초
  • 검증 스크립트: 길이/용량/금지어(효능과장) 체크

2-3. 캡션 + 검수

  • LLM 후기체 캡션 + [광고]·쿠파스 고지문구 자동 삽입 + "댓글로 '나도' 남겨주세요" CTA
  • 완성본 텔레그램 미리보기 → 승인 → 발행. 완성본은 구글드라이브 자동 백업 + 시트에 링크 기록

🚀 3단 — 배포 + 퍼널 자동화 (Day 7~14)

3-1. 업로드

  • 1~2주차(수동): 미리보기 승인 후 사용자가 직접 업로드 (안정 우선)
  • 자동화 전환: 인스타 프로페셔널 계정 전환 → Meta Graph API 캐러셀 게시(공식 경로)
  • 발행 후 콘텐츠TB 자동 갱신

3-2. 댓글→DM 퍼널

  • 1단계(수동): 댓글 수집 크론(Apify, 주기는 사용자 지정) → "나도/키워드" 댓글러 시트화 → 사용자가 DM 발송
  • 2단계(자동): ManyChat(인스타 공식 파트너) 키워드 자동 DM — DM에 해당 제품 쿠파스 검색링크 발송, 발송량 상한 설정(밴 방지)

3-3. 성과 루프

  • 일간 크론: 포스트별 좋아요/댓글/저장/DM수 → 성과TB + 텔레그램 요약
  • 주간: 터진 훅 패턴 분석 → 훅 템플릿 갱신
