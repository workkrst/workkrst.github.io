  1. A안(따라하기) 실현 경로 확보 — 이 캡션들("타임지 선정 세계 최강 동안 1위", "냉부해 셰프들 바로 주문")은 곧 유튜브 역검색 키워드. 같은 문구로 검색하면 원본 방송 클립이 나오고, 그 클립을 우리 슬라이드 2 소재로 사용
  2. 검증된 캡션 템플릿 30개 — 위 공식 5단 구조 + 실제 예시 문구를 그대로 템플릿화. LLM에 "이 구조 유지 + 트리거 단어만 교체" 방식으로 생성
  3. 셀럽 우선순위 — 하지원·최수종·하희라·추안도탄·오은영·손예진·화사 (3개 이상 계정이 반복 사용 = 검증된 얼굴)
  4. 차별화 포인트 — 이 계정들은 릴스/사이드카 위주. 우리는 캐러셀 1장 셀럽 훅카드로 진입 — 검증된 포맷 + 차별화된 첫인상
  5. 인포크링크 설계 반영 — "프로필 링크 NNN번" 번호 시스템을 우리 VPS 페이지에 동일 적용 (키워드별 버튼 + 클릭 카운트)
  6. 주의 — 이 계정들의 "신체나이 30대", "염증수치 0.9" 같은 무근거 과장은 그대로 복사 금지. 캡션 생성 시 효능 표현은 건강기능식품법 안전선 내로 필터링
